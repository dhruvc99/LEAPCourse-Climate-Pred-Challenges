# **Project 3: notebooks**

This folder contains notebooks and resources for **Project 3**, where we reconstruct surface ocean pCO₂ from sparse observations using Earth System Model (ESM) outputs and machine learning techniques.

- **`pco2_reconstruction_group4.ipynb`**  
  Our submission notebook.
  
- **Approaches**  
  Contains notebooks with alterations to the initial methdology that were used to produce the reconstructions considered in `pco2_reconstruction_group4.ipynb`.

- **Helper Notebooks**  
  Contains notebooks that help with loading/processing data and ensuring things look right in the persistent storage.
